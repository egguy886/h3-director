# H3 Director 八步导演工作流更新设计

## 目标

把资产先行、空间连续性、首尾帧交接、镜头调度、动作因果、声音设计和生成后修正统一成 H3 Director 的强制生产门，降低人物漂移、空间跳轴、无重力动作、声音缺失和跨段不连贯。

## 保持不变的约束

- MiniMax H3 官方字段名称、字段顺序、模式差异、引用标签和时间语法仍由 `h3-prompt-writing` 及其参考文件决定。
- 默认使用中文导演描述；海外剧本的已批准对白保留原版英文并放在官方 `<d>[English] ...</d>` 标签中。
- 不把 Seedance 的 `@asset` 语法写入 H3 提示词。
- 已验收视频的实际尾帧才是连续性事实；计划尾帧不能替代真实尾帧。

## 核心流程

每个新片段按照以下顺序完成：

1. 固定资产：列出资产、唯一主责维度、允许转移的特征和禁止泄漏的特征。
2. 明确空间：建立人物、道具、危险源、出口的空间图，锁定轴线、左右关系、运动方向、数量和接触关系。
3. 规定首帧：独立片段定义可执行首帧；连续片段使用验收片段真实尾帧作为 `<Picture 1>` / `ref_image_0`。
4. 规定镜头运动：每个镜头一个主要运动和明确终点，禁止模型自行旋转、翻转或增加切镜。
5. 规定动作顺序：按照触发 → 动作 → 受力/反应 → 结果写可观察动作，优先保证手部、重力、接触和变身可读。
6. 规定声音：分离对白/口型、角色音色参考、环境声、动作声、呼吸和静默；连续短剧默认不生成配乐。
7. 规定最后一帧：尾帧必须稳定、可解码、可复用，并明确下一段要继承的物理状态。
8. 连续性修正：检查实际生成视频，只给出一个验收结论；返修时只改变一个主变量，并更新观察到的尾帧。

## 交付与验证

- 八步完成前不得编译最终 H3 提示词。
- 交付包含导演简报、资产上传表、干净 H3 提示词和连续性交接记录。
- H3 提示词继续通过 `validate_h3_prompt.py`；导演合同另由 `validate_director_contract.py` 检查八步标题、首尾帧和修正结论。
- 新增的详细规则放入 `references/eight-step-director-workflow.md`，主 `SKILL.md` 只保留门槛、顺序和交付要求。

## 非目标

- 不修改 H3 模型、ComfyUI 工作流或音频生成能力。
- 不把 Higgsfield/Seedance 的平台语法、分辨率承诺或角色声音锁定能力当作 H3 功能。
- 不自动覆盖已验收资产、提示词或视频。
