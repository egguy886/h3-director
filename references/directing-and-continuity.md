# 导演契约与真实尾帧接力

## 八步导演契约

每段投产前必须完成以下八项：

1. `assets`：明确人物、服装、场景、道具、声音和首帧各由哪个批准资产控制；一项受控事实只设一个主权来源。
2. `space`：建立人物位置、距离、朝向、入口出口、180度轴线、视线和银幕运动方向。
3. `openingState`：写成第一帧中可以直接看见的物理状态；后续段必须来自上一段验收 take。
4. `camera`：给出戏剧任务、起点、触发、路径、速度、构图不变量和终点。
5. `actionPerformance`：动作有因果和重量；表演以目标、阻碍、策略、倾听和可见反应组织。
6. `dialogueSound`：安排逐字对白、说话人、口型、声音身份、环境声和必要静默；连续短剧默认不自动添加音乐。
7. `finalState`：明确人物、道具、伤势、光线、银幕方向和稳定 0.3–0.5 秒尾帧。
8. `reviewStrategy`：预先写出 KEEP 条件与最可能的单变量修复方向。

## 镜头语言

每个镜头只有一个主要戏剧任务。使用可执行的几何关系，不写空泛的“史诗感运镜”：

```text
Start state -> trigger -> camera path -> framing invariant -> end state -> hold/cut
```

需要时说明机位相对人物的前后左右、相机高度、距离、角度、景别、镜头焦段和前中后景。焦段服务空间效果，不作为装饰词。

连续性必须锁定：

- 180度轴线和视线；
- 人物银幕方向；
- 道具所在手；
- 人物与场景锚点的位置；
- 伤势、雨湿、污损和破坏状态；
- 主光方向、色温和实景光半径。

切镜必须由动作、视线、声音、信息、情绪转折或节奏标点触发。禁止同一时刻既 locked-off 又移动、摄影机穿墙、无动机越轴、无法在时长内到达的机位和遮住关键动作的构图。

## 表演与动作

表演写可观察行为，不直接命令“表现悲伤/愤怒”。为在场人物确定当前目标、阻碍、策略和策略变化；让眼神先于头部、反应在对方句尾前开始，并给手部一个真实任务。关键对白前后的停顿必须发生判断、拒绝或动作中断。

动作戏按因果链写：

```text
发起 -> 防守/闪避 -> 接触 -> 受力反应 -> 环境反馈 -> 下一动作起点
```

锁定武器手位、距离、重心、质量和破坏方向。巨兽、龙和机甲用启动重量、覆盖范围、速度差和环境反馈体现尺度，不只写身高数字。

## 真实尾帧接力

可以一次规划所有片段，但不能一次把所有后续首帧视为最终。生产顺序：

1. 生成当前 `GENERATION_READY` 片段。
2. 完整观看并按 review 规则判定。
3. 只有 KEEP take 标记为 `ACCEPTED`。
4. 从该 take 提取真实尾帧，并记录观察到的角色、道具、光线和银幕方向。
5. 执行 `handoff`，下一段进入 `RECOMPILE`。
6. 用真实 Picture 1 重写下一段开场状态、镜头起点和必要的局部调度。
7. 写入 `promptCompiledForTakeId`，重新校验，再进入 `GENERATION_READY`。

不得使用计划尾帧、被拒 take、尚未观看的视频或上一版被替代 take。替换已接力的 take 会使下游 overlay 失效；若下游已有已验收片段，应停止并要求明确的级联重做决定。

## 返修

- `KEEP`：可以进入 canon 接力链。
- `POST-FIX`：故事和连续性正确，仅需后期可修的轻微问题。
- `REROLL`：提示词正确但采样失败；保持提示词或只改变一个生成变量。
- `REWRITE`：提示词、资产绑定、时间、对白或调度有问题；修一个主要原因后再生成。

每次返修记录主变量。不要同时改角色、镜头、动作、光线和对白，否则无法知道哪项修复有效。
