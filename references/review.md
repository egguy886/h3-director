# 提示词、生成片段与整集审查

## 投产前

依次检查：

1. Profile 数学正确；fixed-delivery 为精确段数和时长。
2. 所有节拍恰好认领一次且顺序不变。
3. 对白台账、片段对白和 `<d>` 完全一致，容量可行。
4. 跨场符合当前 profile。
5. 八步导演契约完整。
6. 角色、场景、道具、声音和首帧均有唯一资产权威。
7. 镜头起点、触发、路径、不变量和终点可在时长内完成。
8. H3 字段、字段顺序、对齐句、标签和 speaker ID 合法。
9. 非对白正文为英文，不含生产元数据和外平台语法。
10. 当前片段拥有合法 opening asset；后续片段拥有上一段 accepted take 的 handoff，并已针对该 take 重编译。

运行：

```powershell
node scripts/h3-drama-director.mjs validate <package.json> --check-assets
```

错误必须清零。`VISUAL_EMBELLISHMENT_SEMANTIC_REVIEW` 等警告不能机械忽略，需要确认没有剧情影响。

## 单段实际视频

从头到尾观看并检查：

- 剧情：认领节拍是否全部发生，顺序和结果是否正确。
- 对白：是否有声音、说话人正确、逐字完整、没有截断或额外台词。
- 口型：画内对白嘴部可见且与声音同步；画外音没有错误对口型。
- 表演：反应、视线、停顿和状态惯性自然，没有木偶式等待台词。
- 人物：脸、发型、年龄、体型、服装和声音身份一致。
- 物理：道具手位、动作因果、受力、伤势、污损和环境破坏连续。
- 镜头：关键动作可读，轴线和银幕方向正确，没有无意义乱晃、穿模和随机切镜。
- 光线：方向、色温、阴影、实景光半径和曝光不跳变。
- 尾帧：结尾稳定 0.3–0.5 秒，可准确提取人物、道具、光线和方向状态。

对白建议使用 ASR 或强制对齐生成转写，再与 `approvedDialogue` 对比；自动转写只能辅助，关键对白仍需听审。提示词正确不代表模型实际语音一定正确。

## 判定

- `KEEP`：剧情、对白、人物和连续性合格，可输出 canonical handoff。
- `POST-FIX`：仅存在不影响接力、可安全后期修复的问题。
- `REROLL`：规则正确但采样偶发失败。
- `REWRITE`：提示词、时长、资产、对白或调度本身有问题。

嘴不动、没有对白、错词、漏词、换人脸、错道具手位、错误尾帧都不能作为 KEEP。

## 整集拼接

只使用每段 `acceptedTake`。检查段间没有重复或丢失节拍；硬切、动作切、视线切和声音桥符合计划；对白没有被截断、重说或漏说；环境底声、响度和说话人音色连续；人物、道具、伤势、天气和光线不重置；集尾钩子与剧本一致；总时长和画幅符合 profile。
